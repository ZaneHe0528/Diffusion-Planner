# BLUE 启发的自适应轨迹复用计划

> 设计决策经访谈敲定，术语见根目录 `CONTEXT.md`，核心架构决策见 `docs/adr/0001`（重加噪 warm-start）与 `docs/adr/0002`（学习型门控自适应 t_s）。
> 本计划是 `0Falcon/移植计划.md` 的**演进版**：复用其全部 warm-start 基础设施，把原"二期手工自适应 t_s"升级为 BLUE 式的**学习型场景门控**，并抬成核心贡献。
> 决策标注：✅ 访谈确认；🔶 我的推荐默认（你跳过未拍，可改）。

## 一、目标与成功标准

**核心思想（一句话）**：BLUE 在冻结 VLA 的 hidden state 上挂小 gate 决定"是否生成语言"；我们在冻结 planner 的**场景嵌入**（encoder fusion 输出 `encoding`，预去噪即得）上挂小 gate，回归预测**帧间变化距离 d_hat**，据此**自适应设定重加噪起始水平 t_s**——可预测的变化由 gate 事前省算力，不可预测的突发由阈值回退事后兜底。

**成功标准**：
- 相对**固定 t_s** 版（Falcon phase-1），在同等闭环分数下平均 NFE 更低，或同 NFE 下分数更高（**推动 NFE–分数帕累托前沿**）；
- **BLUE 式科学主张**：场景门控在"预测 d / 最终闭环分数"上显著优于 rule-based gate（ego 运动学 / 场景复杂度 / 随机）——即"场景嵌入已编码帧间变化幅度，优于手工特征"；
- val14 / test14-hard 闭环分数（CLS-NR、CLS-R）相对基线掉幅 < 1 分。

**叙事口径**：沿用 Falcon 计划——报告"模型推理（去噪）延迟 / NFE"。方法定位由"训练无关"调整为"**训练极轻量**：冻结 planner + 0.1M 级 gate + 离线标签、无人工标注"（见 ADR-0002）。

## 二、与 Falcon 计划的关系（✅ 演进版）

| 维度 | Falcon 计划（`0Falcon`） | 本计划（演进） |
|---|---|---|
| warm-start 构造 | 重加噪到固定 t_s | **复用，不变** |
| 起始水平 t_s | 固定值扫参 | **学习型场景门控自适应** |
| 一步估计 + 阈值回退 | 安全关键机制 | **复用，作验证式安全网** |
| 邻车 token 匹配 / 匀速外推 | 有 | **复用，不变** |

固定 t_s 版（Falcon phase-1）在本计划里降格为"关键对照基线 + 安全网"，先跑通它再上门控。

## 三、已敲定的设计决策

| 决策点 | 结论 |
|---|---|
| ✅ 定位 | 演进版：gate 取代手工 t_s，复用全部 warm-start 基础设施 |
| ✅ gate × 阈值关系 | **两者都保留**：gate 事前预测 d_hat→设 t_s（主动分配）；一步估计 + 阈值回退作验证式安全网（通过路径近乎免费，仅回退时 +1 NFE） |
| ✅ 标签 d 定义 | **与阈值度量完全一致**：ego-only、重叠段（79/80）、物理空间（米）逐点欧氏距离取 **max**、对照完整去噪。离线测量，是 gate 的回归目标（即 `CONTEXT.md` 的"帧间变化距离"） |
| 🔶 gate 输入 | **encoding-only**（mean-pool over 有效场景 token）。参考轨迹 / ego 运动学留作消融行 |
| 🔶 gate 输出与映射 | 回归 d_hat（物理米）→ 经离线标定的**分箱映射**到操作点 (t_s, steps)；**最高档 = 完整去噪**（主动短路）。映射边界与 ε 在小开发集扫 |
| 🔶 gate 结构与训练 | 单隐层 MLP（hidden≈128，~0.1M 级，对齐 BLUE）；回归用 Huber/MSE on 标准化 d；planner 全程冻结 |

## 四、每帧推理流程（设计稿）

```
compute_planner_trajectory(当前帧):
  1. 数据处理(现有) → model_inputs + 选中邻车 track tokens
  2. encoder 前向 → encoding(场景嵌入)         # 预去噪即得, 后续去噪本来就要算
  3. 若缓存为空(场景首帧)或上帧回退失败:
       完整去噪(现有路径, NFE≈11); gate 不参与
     否则:
       a. 参考轨迹: 缓存 ego x0 → SE(2) 对齐 + 时移1下标(末尾匀速补点)
       b. 场景门控: d_hat = gate(mean-pool(encoding))     # 微型 MLP, 不计 NFE
       c. d_hat → 操作点(t_s, steps): 分箱映射
          └─ 若落在最高档: 直接完整去噪(主动判难, 跳过 warm-start)
       d. 邻车 x0: token 命中→上帧对应预测对齐; 未命中→匀速外推
       e. 归一化 → 拼装[current_state, x0_ref] → 前向加噪到 t_s
       f. 一步估计(= t_s 处首个 solver eval): DiT 前向 → x0_hat
       g. 阈值验证(安全网): max_t ||x0_hat_ego − ref_ego||₂ ≤ ε ?
          ├─ 是: 从 t_s 跑少步(复用 f 的 eval, 省1 NFE)
          └─ 否: 被动回退完整去噪(f 计入 NFE)
  4. 更新缓存: 本帧 ego/邻车最终轨迹、anchor ego state、邻车 token 列表
  5. 记录: NFE、d_hat、d_meas、选中操作点、主动判难/被动回退(诊断 + 可回灌训练数据)
```

**两条到达"完整去噪"的路径**：主动（c：gate 预判难帧）+ 被动（g：验证失败）。前者省掉无谓的 warm-start 尝试，后者守住突发安全。

## 五、门控：标签、特征、输出、训练

- **标签来源（零额外成本）**：复用 M1 离线逐帧回放。逐帧跑完整去噪，缓存 `(mean-pool(encoding), d)` 配对；d 即"帧间变化距离"。
- **数据规模**🔶：采样数百~1–2k nuPlan scenario，逐帧 → 数万配对。BLUE 式**冗余下采样**（停车/相邻帧 cos>0.99 的段降采样，避免静止帧主导）。按 scenario 划分 train/val/test 防泄漏。
- **特征**🔶：hero = mean-pool(encoding)；消融 = +参考轨迹、+ego 运动学、rule-based-only。
- **输出 → 操作点**🔶：d_hat 落入分箱 → (t_s, steps)，例如 `{低: t_s≈0.2/1–2步, 中: 0.3/2–3步, 高: 0.5/3–4步, 满: 完整去噪}`；具体档位与边界扫参定。
- **训练目标**🔶：标准化 d 上的 Huber/MSE 回归；不触碰 planner。
- **可行性前置**：先做线性/小 MLP 回归探针验证 encoding 能预测 d（见 M-probe），过了才正式训练 gate。

## 六、评测矩阵（全量，里程碑 M4 执行）

| 行 | 配置 | 目的 |
|---|---|---|
| 1 | 基线 DPM-Solver 10 步（NFE≈11） | 锚点 |
| 2 | 直接降步数（同 NFE 预算，无 warm-start） | 对照：warm-start 的价值 |
| 3 | **固定 t_s warm-start**（Falcon phase-1，最优单点） | **关键对照**：自适应相对固定的增量 |
| 4 | **rule-based gate**（ego 速度/加速度/曲率/距前车阈值 + 随机）→ t_s | **BLUE Table 7 类比**：证明 encoding 优于手工特征 |
| 5 | **场景门控自适应 t_s**（本方法，扫参后最优） | 主结果 |

- 数据集：val14 + test14-hard；挑战：CLS-NR + CLS-R 都报。
- 指标：闭环分数、平均 NFE、NFE 分布、回退率（**主动判难 / 被动回退分开报**）、gate 回归误差与相关性、GPU 去噪延迟。
- 扫参（操作点集 × ε × 分箱边界）只在小开发集做。
- guidance 不进主表（与 Diffusion-Planner 论文主结果口径一致）。

## 七、里程碑

### M0：查新（半天）
沿用 Falcon M0，**补查**：2025–2026 是否已有"在冻结扩散/规划主干的 hidden state 上学 gate 控制去噪步数/起始水平"的工作，确认增量（场景嵌入预测帧间变化 → 自适应 t_s + 安全回退）站得住。

### M1：基础设施 + 离线回放（核心工程量，与 Falcon 共用）
- 实现缓存、SE(2) 对齐 + 时移、重加噪、一步估计、阈值判定（集中在 `diffusion_planner/model/diffusion_utils/warm_start.py`，配置开关控制，关掉即基线）；
- 离线逐帧回放脚本：除产出"参考 vs 完整去噪距离分布图"（定 ε、复刻 Falcon Fig.2）外，**额外缓存 `(encoding, d)` 配对**作为 gate 训练集；
- **验收**：对齐可视化无误；距离分布集中 + 可分长尾。

### M-probe：可行性探针（去风险，门槛性里程碑）★
- 在 `(encoding, d)` 上拟合线性回归 / 小 MLP，对比 **encoding vs ego 运动学特征** 预测 d 的误差与相关性；
- **门槛**：encoding 显著优于运动学、相关性可用 → 放行训练 gate；**不过则止损**，退回固定 t_s（Falcon phase-1 仍是可交付结果）。

### M2：固定 t_s 闭环冒烟（= Falcon phase-1 baseline + 安全网验证）
- 接入闭环，固定 t_s 单点 + 阈值回退；建 20–30 场景小开发集；
- **验收**：分数无灾难性崩坏（掉幅 < 5 分），平均 NFE 显著下降，回退率合理。

### M3：训练场景门控 + 集成 + 扫参
- 训 gate（M1 数据），集成进流程（流程图 b/c）；
- 小开发集扫操作点集 × ε × 分箱边界，观察 **NFE–分数帕累托前沿是否优于固定 t_s**；
- **验收**：小开发集上自适应版在帕累托前沿上压过固定 t_s，分数恢复到基线 ±1 分内。

### M4：全量评测 + 消融 + 写作素材
- 跑第六节评测矩阵（含 rule-based gate 消融）；
- 汇总：分数表、NFE/延迟/回退率表、gate 激活与 t_s 分布、按场景类型分解。

## 八、风险清单

| 风险 | 应对 |
|---|---|
| **encoding 预测不了 d**（核心研究风险） | M-probe 前置兜底，不过则止损退回固定 t_s |
| gate 把难帧误判为易帧（低 t_s 太激进） | 阈值验证安全网兜底：一步估计实测 d_meas 超 ε 仍被动回退 |
| **训练/闭环分布不匹配**：gate 训练数据来自 full-denoise 回放，闭环里 ego 走的是 warm-start 产物 | M3 观察；必要时用闭环数据回灌再训一轮（DAgger 式，作为消融） |
| 闭环自激/模态漂移（warm-start 帧间自相关） | 沿用 Falcon：观察 + 必要时"每 N 帧强制完整去噪"保险 |
| 加速比天花板（基线仅 11 NFE，本就 3–4x） | 叙事按实测，强调"自适应优于固定 t_s + 分数不降"，而非倍数 |
| 已有相近工作 | M0 查新前置 |
