# 用学习型门控预测帧间变化、自适应设定起始水平 t_s（从"训练无关"转为"训练极轻量"）

Falcon 适配版原本定位为训练无关加速（见 `CONTEXT.md` 叙事口径与 ADR-0001）。固定 t_s 对易/难帧一刀切：易帧浪费算力，难帧 t_s 又可能不够、频繁触发回退。原计划"二期增强"想用手工的 `d → t_s` 映射做自适应，但 d（帧间变化距离）要先做一步估计才知道，存在"先有鸡还是先有蛋"。

决策：受 BLUE 启发，在**冻结** planner 的场景嵌入（encoder fusion 输出，预去噪即得）上训练一个 0.1M 级 MLP 门控，**事前**回归预测当前帧的帧间变化距离 d_hat，据此自适应设定 t_s（从激进低 t_s 到完整去噪的全谱）。训练标签来自离线完整去噪统计，无需人工标注。一步估计 + 阈值回退作为**验证式安全网**保留。这把方法从"训练无关"改为"训练极轻量：冻结主干 + 微型 gate"。

理由：(1) BLUE 证明冻结 hidden state 上的小 gate 能学到比手工特征（运动学、场景复杂度）更好的"效用信号"，且推理开销可忽略；本项目里场景嵌入是现成、预去噪即得的对应物。(2) 自适应 t_s 把固定 t_s 的一刀切换成按帧分配算力，目标是推动 NFE–分数帕累托前沿。(3) gate 事前预测打破了"d 要先一步估计"的循环依赖。(4) 训练成本极小（微型 MLP + 离线标签），不触碰 planner 权重，风险可控。

被否决的备选：(a) 保持训练无关 + 手工 `d → t_s` 映射（原二期方案）——舍弃，手工映射要么循环依赖一步估计、要么只能用粗特征，预期不如学习型；但作为对照保留一行 rule-based gate 消融。(b) 直接微调 planner 实现自适应——舍弃，违背轻量/低风险原则，且失去"现成 hidden state 已编码帧间变化"的科学卖点。

核心研究风险：encoding 能否真预测 d。上线前以线性回归可行性探针兜底（仿 BLUE 的 logistic 回归 sanity check），探针不过则整条路线及时止损。
