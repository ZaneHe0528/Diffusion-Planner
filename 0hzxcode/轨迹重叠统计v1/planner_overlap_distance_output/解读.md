这是**按“新规划轨迹上的未来时刻”分组**后的统计表。每一行回答的是：

> 在“距离新规划起点 `horizon_time_s` 秒”这个未来时刻，上一帧 planner 的未执行轨迹，和新一帧 planner 轨迹，在 global XY 平面上的欧氏距离分布如何？

你这次跑的是 **1118 个 scenario、1300 万+ 个比较点**，比较的是 **rear_axle** 位置，**相邻规划步**（`pair_stride=1`），且**排除了新轨迹第 0 个点**（当前 ego state）。

---

## 各列含义

| 列名 | 含义 |
|---|---|
| `horizon_time_s` | 比较点相对**新规划起点**的未来时间（秒）。`0.099999` 约等于 **0.1s**，也就是新规划后第一个未来采样点。 |
| `count` | 落在该 `horizon_time_s` 的比较点数量。这里是 **113348** 个 `(旧规划, 新规划, 同一绝对时刻)` 样本。 |
| `mean` | 这些点的平均距离（米）。**0.041 m ≈ 4.1 cm**。 |
| `std` | 距离标准差（米）。**0.050 m**，说明有一定离散。 |
| `min` | 最小距离（米）。接近 0，说明有些点几乎完全一致。 |
| `p50` | 中位数（50% 分位）。**0.026 m ≈ 2.6 cm**，一半比较点距离 ≤ 2.6 cm。 |
| `p75` | 75% 分位。**0.056 m ≈ 5.6 cm**。 |
| `p90` | 90% 分位。**0.097 m ≈ 9.7 cm**。 |
| `p95` | 95% 分位。**0.132 m ≈ 13.2 cm**。 |
| `p99` | 99% 分位。**0.225 m ≈ 22.5 cm**。 |
| `max` | 最大距离（米）。**1.57 m**，说明存在少量 outlier。 |

## 这一行具体在说什么

第 2 行：

```csv
0.099999,113348,0.041...,0.050...,...,0.026...,...,1.57...
```

可以读成：

- 在**新规划后约 0.1 秒**的未来时刻；
- 共有 **113348** 次“上一帧未执行轨迹 vs 新一帧规划轨迹”的比较；
- **典型差异约 2.6 cm**（p50）；
- **90% 的点差异 < 9.7 cm**；
- 但**最极端**的一次差异达到了 **1.57 m**。

这说明：**最近未来（0.1s）整体上 planner 帧间比较一致，但尾部仍有明显 outlier**。

---

## 两个容易误解的点

1. **`horizon_time_s` 不是仿真绝对时间**  
   它是“相对新规划起点的未来时间”。越往后（0.2s、0.5s、1.0s…），通常 mean / p90 会变大，因为两帧 planner 对未来预测更容易发散。

2. **为什么有 `0.099999` 和 `0.1` 两行？**  
   这是浮点时间戳分组导致的（微秒转秒后 round 到 6 位小数）。两行含义几乎一样，看趋势时可合并理解成 **0.1s**。

## 和 Falcon 阈值的关系

如果你后面要做 warm-start 阈值 ε，这张表很有用：

- **0.1s 的 p50 ≈ 2.6 cm**：说明“正常帧间抖动”量级很小；
- **0.1s 的 p95 ≈ 13 cm**：可作为 ε 的参考上界之一；
- **max = 1.57 m**：这类 outlier 往往对应换道、急弯、强交互等场景，正好说明为什么需要**阈值回退**。
