# Falcon 帧间复用移植计划

> 设计决策经访谈敲定，术语见根目录 `CONTEXT.md`，核心架构决策见 `docs/adr/0001`。
> 前置事实（已验证）：基线 DPM-Solver++ 10 步 / NFE≈11，去噪占 GPU 推理 ~90%（19.3ms / 21.4ms）；checkpoint 与 nuPlan 数据就绪；`DPM_Solver.sample()` 原生支持 `t_start`；轨迹步长 0.1s 与 replan 间隔相同，时移 = 平移一个下标。

## 一、目标与成功标准

**交付物**：论文级贡献——将 Falcon 的部分去噪复用机制适配到 nuPlan 闭环自动驾驶规划。

**成功标准**：
- val14 / test14-hard 闭环分数（CLS-NR、CLS-R）相对基线掉幅 < 1 分；
- 平均 NFE 从 11 降到 ≤ 3（去噪延迟 19.3ms → ~5ms，3–4x）；
- 同 NFE 预算下显著优于"直接降步数"对照。

**叙事口径**：报告"模型推理（去噪）延迟 / NFE"，不是端到端延迟。闭环为同步仿真，结论形式为"分数不降 + NFE 降 N 倍"。

## 二、已敲定的设计决策

| 决策点 | 结论 |
|---|---|
| 方法定位 | 适配版：保留核心三件套（帧间复用、一步估计、阈值回退），砍掉多帧 buffer、softmax 采样、探索率 δ |
| warm-start 构造 | 重加噪：缓存上一帧干净轨迹 x0（物理空间），SE(2) 对齐 + 时移后用 VPSDE 前向公式加噪到 t_s（ADR-0001） |
| 起始水平 t_s | 一期固定值扫参（0.2 / 0.3 / 0.5），自适应 t_s 作为二期增强 |
| 阈值判定 | 物理空间、只看 ego、重叠段逐点欧氏距离的 **max**，超 ε 即回退完整去噪 |
| 邻车 token | track token 匹配（`data_processor` 透出选中邻车 token 列表）；未匹配邻车用匀速外推作粗 x0 |
| 评测矩阵 | 4 行配置 × val14/test14-hard × NR/R，guidance 不进主表 |
| 工作流 | 三层验证金字塔：离线逐帧回放 → 小开发集闭环 → 全量闭环 |

## 三、每帧推理流程（设计稿）

```
compute_planner_trajectory(当前帧):
  1. 数据处理（现有）→ model_inputs + 选中邻车 track tokens
  2. 若缓存为空（场景首帧）或上帧回退失败:
       完整去噪（现有路径, t: T→0, NFE≈11）
     否则:
       a. 参考轨迹构造: 缓存的 ego x0（物理空间, 上帧 ego 系）
          → SE(2) 变换到当前 ego 系 → 时移 1 个下标（末尾匀速补点）
       b. 邻车 x0: token 匹配命中 → 上帧对应预测同样对齐;
          未命中 → 从当前观测匀速外推 80 步
       c. 归一化 → 拼装 [current_state, x0_ref] → 前向加噪到 t_s:
          x_ts = mean_coeff(t_s)·x0 + std(t_s)·z,  z~N(0,I)
       d. 一步估计: DiT 前向(x_ts, t_s, 当前观测编码) → x0_hat（x_start 型直接输出）
       e. 判定: 反归一化后, max_t ||x0_hat_ego[t] − ref_ego[t]||₂ ≤ ε ?
          ├─ 是: 从 t_s 跑 DPM-Solver 少步（multistep 首个 model eval 复用 d 的结果, 省 1 NFE）
          └─ 否: 回退完整去噪（d 的那次前向计入 NFE 开销, 诚实记账）
  3. 更新缓存: 本帧 ego/邻车最终轨迹（物理空间）、anchor ego state、邻车 token 列表
  4. 记录: 本帧 NFE、是否回退、判定距离（写入诊断日志）
```

### 技术细节与已知陷阱

- **SE(2) 变换**：heading 用 (cos, sin) 表示，旋转时该分量也要随 Δθ 旋转；变换必须在物理空间做（`StateNormalizer` 反归一化 → 变换 → 归一化）。
- **首 token 约束**：现有 `initial_state_constraint`（correcting_xt_fn 每步把各 token 首元素重置为当前状态）在 warm-start 路径同样保留。
- **基线初始化的 0.5 缩放**：现有代码 `xT = randn(...) * 0.5`（非标准差 1）。重加噪应按训练时 `marginal_prob` 公式用标准正态 z（数学正确）；离线回放阶段对比验证一次"标准 z vs 0.5·z"以排除意外。
- **t_s 与步数**：从 t_s 起步时 solver 步数相应缩减（如 t_s=0.3 时 2~3 步），具体组合在扫参中确定；`skip_type="logSNR"` 保持与基线一致。
- **NFE 记账**：阈值通过 = 1（一步估计，复用）+ 少步；回退 = 1 + 11。报告平均 NFE 时包含一步估计的开销。
- **缓存失效**：场景切换（`initialize` 调用）时清空缓存。

## 四、评测矩阵（全量，里程碑 M4 执行）

| 行 | 配置 | 目的 |
|---|---|---|
| 1 | 基线 DPM-Solver 10 步（NFE≈11） | 复现官方分数，锚点 |
| 2 | 直接降步数 2/3/5 步，无 warm-start | 关键对照：同 NFE 预算下 warm-start 的优势 |
| 3 | 朴素 warm-start（无阈值回退） | 消融：阈值回退在突发场景的必要性（预期差距主要在 test14-hard / CLS-R） |
| 4 | 完整方法（扫参后最优 ε、t_s） | 主结果 |

- 数据集：val14 + test14-hard；挑战：CLS-NR + CLS-R 都报。
- 指标：闭环分数、平均 NFE、回退触发率、GPU 去噪延迟。
- guidance 不进主表（与 Diffusion-Planner 论文主结果口径一致）。
- 扫参（ε × t_s）只在小开发集上做。

## 五、里程碑

### M0：查新（半天，动手前）
快速调研 2025–2026 年是否已有人在 nuPlan/驾驶闭环上做扩散 planner 的 warm-start/流式去噪，确认增量站得住（坐标系对齐 + 邻车联合去噪帧间匹配 + 安全回退机制是本项目的差异点）。

### M1：基础设施 + 离线验证（核心工程量）
- `data_processor` 透出选中邻车 track tokens；
- 实现缓存、SE(2) 对齐 + 时移、重加噪、一步估计、阈值判定（建议集中在新模块 `diffusion_planner/model/diffusion_utils/warm_start.py`，planner/decoder 只留钩子；全部行为受配置开关控制，关掉即基线）；
- 离线逐帧回放脚本：挑 5–10 个 log 场景，逐帧同时算完整去噪与参考轨迹，产出 ①参考轨迹 vs 完整去噪的距离分布图（定 ε 量级，复刻 Falcon Fig.2 的论证）②对齐可视化叠图（肉眼验证坐标变换——这是最易错且不报错的环节）。
- **验收**：可视化对齐无误；距离分布集中在小值区，存在可分的长尾（说明阈值有判别力）。

### M2：朴素 warm-start 闭环冒烟
- 接入 nuPlan 闭环，固定 t_s 单点（如 0.3），无阈值回退；
- 建 20–30 场景的小开发集 `scenario_filter`；
- **验收**：小开发集分数无灾难性崩坏（掉幅 < 5 分），平均 NFE 显著下降，无报错跑完。

### M3：完整方法 + 扫参
- 加阈值回退 + 邻车 token 匹配 + 匀速外推；
- 小开发集上扫 ε × t_s（约 3×3 组合），观察分数–NFE 帕累托前沿，定最优组；
- 顺带验证回退率合理（预期 <10%，过高说明 ε 太紧或对齐有 bug）。
- **验收**：小开发集分数恢复到基线 ±1 分以内。

### M4：全量评测 + 写作素材
- 跑第四节评测矩阵（8 卡，分批）；
- 汇总：分数表、NFE/延迟表、回退率、按场景类型分解的回退分布（论文的安全性论证素材）；
- 若分数达标且有余力：二期增强（自适应 t_s：判定距离 d → t_s 映射），作为加分消融。

## 六、风险清单

| 风险 | 应对 |
|---|---|
| 闭环自激/模态漂移：warm-start 引入帧间自相关，长时间复用可能缓慢漂移且阈值不触发 | M3 观察；必要时加"每 N 帧强制完整去噪"保险（作为消融行报告） |
| 一步估计在 t_s 中段对重加噪输入敏感 | 低风险（重加噪样本在训练分布内）；离线回放阶段直接验证 |
| 加速比不及 Falcon 宣称的 7x | 基线只有 11 NFE，天花板本就 3–4x；叙事按实测，强调"分数不降"而非倍数 |
| 已有相近工作 | M0 查新前置，发现撞车及时调整差异点侧重 |
| 坐标变换 bug 表现为"分数莫名掉"而非报错 | M1 可视化验收强制前置，不跳过 |
